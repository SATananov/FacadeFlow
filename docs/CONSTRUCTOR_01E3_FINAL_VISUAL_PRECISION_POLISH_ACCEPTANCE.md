# CONSTRUCTOR 01E.3 — FINAL VISUAL PRECISION POLISH ACCEPTANCE

Scope: final UI-only precision polish for the technical drawing introduced in 01E / 01E.1 / 01E.2.

## Goal
Keep the user-approved technical drawing composition while making the last high-value visual details calmer and easier to read:
- dimension chain text and witness lines read slightly darker;
- FIELD sequence circles are smaller and more technical;
- selected FIELD outline is visible without dominating the drawing;
- an OPERABLE FIELD with no opening mode uses a neutral solid sash outline instead of a dashed warning-like contour.

## Must hold
- Grid remains visible by default and remains faint.
- In-canvas FIELD identity remains a sequence number in a circle only.
- Single FIELD does not duplicate the overall width with a bay chain.
- 2+ simple horizontal FIELDs retain the bay chain.
- Geometry / topology / FIELD semantics: unchanged.
- Profile Resolution 02A / 02A.2 / 02A.3: unchanged.
- No BOM / cut list / machine logic.
- MACHINE READY: NO.
