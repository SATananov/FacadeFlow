# CONSTRUCTOR 01E.2 — GRID + MINIMAL FIELD BADGE ACCEPTANCE

This polish follows direct operator feedback after visual review.

## User-confirmed drawing preferences
- Keep the CAD grid visible by default behind the construction.
- Keep the grid faint enough that frame / sash / divider lines remain dominant.
- Do not place a multi-line technical card in the middle of every FIELD.
- The default in-canvas FIELD marker is only its sequence number in a small circle.
- Detailed FIELD data remains available in the lower FIELD strip and inspector.

## Dimension rule
- A single FIELD must not duplicate the overall width with a second one-bay chain.
- The bay dimension chain appears only when there are 2+ simple horizontal FIELDs.
- For 2+ simple FIELDs, bay boundaries remain based on outer frame edges and vertical divider centerlines.

## Safety boundary
- Geometry / topology / FIELD semantics: unchanged.
- Profile Resolution 02A / 02A.2 / 02A.3: unchanged.
- BOM / CUT LIST / MACHINE: NO.
- MACHINE READY: NO.
