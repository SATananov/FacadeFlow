# Geometry Evidence Boundary

GEOMETRY EVIDENCE != GENERATED GEOMETRY.

DATABASE RELATIONSHIP EVIDENCE != PHYSICAL JOINT GEOMETRY.

The geometry evidence layer records traceable catalogue, CAD, technical-drawing,
or database facts without creating coordinates, contours, cuts, toolpaths, or
product-model mutations. `UNKNOWN` is a valid result. Automatic geometry is
not allowed.

For the KMG PRELUDE 60 `482.20` Frame / `482.21` Mullion source search, the
recovered `PVC Prelude_bg.pdf` page 2 is recorded as isolated profile-section
evidence only. Its exact SHA-256 provenance belongs to the geometry-evidence
record; it does not establish an assembled joint.
