# PROJECT OPEN 01.1 — Explicit Open Project Action

## Goal

Make opening a saved project obvious to a first-time user.

## Accepted behavior

- The current project name is displayed as information only.
- Opening saved projects uses an explicit **Отвори проект** button.
- **+ Нов проект** remains a separate action.
- The existing Project Manager dialog and project list are preserved.
- Stable internal Project / Offer / Module identities are unchanged.
- PF01 / PF02 persistence, revision and assurance semantics are unchanged.
- Construction topology is unchanged.

## UX rule

A user must not need to infer that clicking the current-project label opens the saved-project list.
