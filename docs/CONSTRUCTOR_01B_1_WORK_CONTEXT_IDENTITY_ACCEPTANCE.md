# Constructor 01B.1 — Work Context Identity

## Goal
Make the current editing context unmistakable at all times.

## Acceptance

- FREE SKETCH CONTEXT: clearly states `Свободна скица · Модул —`.
- OFFER CONTEXT: clearly states `Оферта · Модул N`.
- WORKSPACE BADGE: free mode says `СВОБОДНА СКИЦА · БЕЗ МОДУЛ`; offer mode says `ОФЕРТА · МОДУЛ 0N`.
- BREADCRUMB: persistent path distinguishes free constructor from offer/module constructor.
- ONE CONSTRUCTOR ENGINE: free and offer modes continue to use the same ConstructorShell.
- KEYBOARD WIDTH/HEIGHT EDITING: preserved from Constructor 01B hotfix.
- MOUSE EDGE RESIZE: preserved.
- FREE SKETCH DOES NOT PRETEND TO BE MODULE 1.
- FREE SKETCH MAY LATER BECOME A MODULE WHEN ATTACHED TO AN OFFER.
- AUTOMATIC PRODUCTION GEOMETRY: NO.
- MACHINE READY: NO.
