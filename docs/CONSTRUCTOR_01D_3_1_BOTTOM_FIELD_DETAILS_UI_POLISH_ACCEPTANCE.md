# CONSTRUCTOR 01D.3.1 — Bottom FIELD Details UI Polish

## Scope

This stage is UI-only. It polishes the bottom FIELD details strip introduced in 01D.3.

## Acceptance

- Canvas FIELD labels remain numeric-only white circular badges.
- Bottom FIELD detail cards are taller and easier to read.
- The selected FIELD card has a clearly stronger active state.
- The number badge in each bottom card matches the white circular canvas numbering language.
- FIELD cards keep a stable minimum width and do not collapse when many FIELDs exist.
- The bottom FIELD list scrolls horizontally when needed.
- Clicking a bottom card still selects the same canonical FIELD.
- Opening symbols are preserved.
- Geometry, topology and FIELD semantics are unchanged.
