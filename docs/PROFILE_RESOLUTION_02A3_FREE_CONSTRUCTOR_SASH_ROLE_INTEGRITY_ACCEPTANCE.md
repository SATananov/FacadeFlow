Remove the accidental dependency between an OPERABLE FIELD sash-profile target and the old offer-side product-type preset workflow.

- CONSTRUCTOR MODULE TYPE SOURCE: `constructor`
- WINDOW -> ROLE `sash`
- DOOR -> ROLE `door-sash`
- STANDARD PRODUCT TEMPLATE REQUIRED: NO
- CHANGING WINDOW / DOOR RECONCILES INCOMPATIBLE SASH ASSIGNMENT: YES

- FIX FIELD -> NO SASH PROFILE TARGET

- PROFILE-AWARE MACHINE GEOMETRY: NO
- BOM / CUT LIST / MACHINE OUTPUT: NO
