# Technical Drawing Reference Library

This directory stores human-provided technical-drawing references and their evidence descriptors. The categories are:

- [Windows](windows/README.md)
- [Doors](doors/README.md)
- [Combined door + window](combined/README.md)
- [Opening symbols](opening-symbols/README.md)
- [Dimensions](dimensions/README.md)
- [Sliding](sliding/README.md)
- [Reference entry template](REFERENCE_ENTRY_TEMPLATE.md)

## Evidence and attachment rules

- Record each reference using the template and assign an evidence class and a scoped human-approval statement.
- Store actual supplied files only when they are explicitly available and authorized to be added. Never fabricate or reconstruct a screenshot and never claim an image was inspected if it is absent.
- A visual reference can guide appearance and drawing hierarchy; it does not establish production geometry, catalogue compatibility, or physical dimensions.
- Mark example values EXAMPLE ONLY. Unsupported information remains UNKNOWN.
- Keep source, approval, allowed use, and prohibited inference explicit.

The Human Reference Set 01 currently exists as textual descriptors based on the user-provided descriptions. No image files were identified or added for this task.
