# CONSTRUCTOR 01E.4 — OPENING SYMBOL SASH ANCHORING

## Goal
The opening symbol must visually belong to the sash, not float inside it.
This follows the technical drawing grammar visible in the supplied SkyGlazing reference without copying its UI.

## Visual contract
- The OPERABLE sash remains the visual boundary for the opening symbol.
- After the 01E.5.1 sash-profile correction, the opening geometry anchors to the inner sash / glazing contour rather than floating inside the glazing area.
- Side-hinged lines start at the two hinge-side inner sash corners and converge on the opposite inner sash edge at handle height.
- Tilt lines start at the lower inner sash corners and meet the top-center inner sash edge.
- Tilt-turn combines those anchored lines.
- The handle connection crosses the schematic sash profile band to the handle pivot; no endpoint floats in open glazing space.
- LEFT and RIGHT remain true mirror variants.

## Non-goals / boundaries
- Geometry / topology / FIELD semantics: unchanged.
- Opening mode / handing domain logic: unchanged.
- Profile Resolution 02A / 02A.2 / 02A.3: unchanged.
- BOM / CUT LIST / MACHINE: no.
- MACHINE READY: NO.
