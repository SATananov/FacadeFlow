# CONSTRUCTOR 01E.5.1 — SASH PROFILE MITRE CORRECTION

This hotfix corrects the rejected 01E.5 visual interpretation.

## Reference reading
The supplied SkyGlazing reference does not show four decorative diagonal strokes floating in the glazing area. It shows an operable sash as a profile ring with an outer contour and an inner glazing contour. The 45-degree corner seams live only across that profile band.

## Acceptance
- OPERABLE fields render a schematic sash profile ring: outer contour + inner contour.
- The four 45-degree mitre seams connect the outer and inner sash corners only.
- No sash mitre line extends into the glazing area.
- Opening symbols terminate on the inner sash / glazing contour, matching the reference reading.
- Handle-side opening lines connect through the sash band to the handle pivot without floating endpoints.
- FIX fields do not receive a sash profile ring.
- The ring width is visual/schematic only. It is not a catalog-derived profile face or production dimension.

## Invariants
- Construction geometry: unchanged.
- FIELD topology and semantics: unchanged.
- Profile Resolution 02A / 02A.2 / 02A.3: unchanged.
- BOM / CUT LIST / MACHINE: NO.
- MACHINE READY: NO.
