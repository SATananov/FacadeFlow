# CONCEPT 02 — Offer Basics Acceptance

Base concept: CONCEPT 01 clean start.

## Purpose

The first real FacadeFlow workflow begins with one offer and its common parameters before individual modules are created.

## User flow

1. The user presses **Създай оферта**.
2. The offer screen collects **Клиент** and **Обект**.
3. The common offer parameters are selected:
   - System: **Prelude 60**
   - Type: **Прозорец**
   - Color: **Бяло**
   - Glazing thickness: **24 mm / 32 mm / 44 mm**
   - Hardware: **Siegenia / Maco**
   - **Общи условия** free text
4. The screen clearly declares that the next step is **Модули**.

## Important scope boundary

The exact glazing compositions are not invented in CONCEPT 02. Only the confirmed thickness values are represented until the notation from the real workflow is confirmed.

CONCEPT 02 does not create Module 1 / Module 2 / Module 3 yet. It only prepares the common offer data and declares modules as the next step.

## Visual continuity

The CONCEPT 01 header remains unchanged in principle:

- Nadezhda branding
- dark technical grid header
- cyan / orange accent line
- exactly one primary header action: **Създай оферта**

No old Demo navigation, AI workspace, PROFILE DATA or CAD workflow is introduced.
