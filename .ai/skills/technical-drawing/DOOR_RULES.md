# Door Technical Drawing Rules

## Approved high-level conventions

- A door is a functional region/module identity; it may contain an operable leaf.
- An opening symbol belongs to the actual operable leaf.
- Handing and opening direction must be explicit. Do not infer them from the word “door,” region location, or an unclassified picture.
- Door dimensions are presented as technical dimensions outside the sketch, tied to actual represented bounds.
- Keep functional identity separate from field type, opening mode, and handing.

## Unknown production facts

- Physical threshold and bottom-frame behavior remain UNKNOWN unless separately approved and verified.
- These rules do not define profile dimensions, sash overlap, hardware, catalogue compatibility, or production assembly geometry.

Refer to the existing door-specific approved project rules where applicable; this knowledge file does not replace them. See [opening symbol rules](OPENING_SYMBOL_RULES.md) and [evidence rules](REFERENCE_EVIDENCE_RULES.md).
