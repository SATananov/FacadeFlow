# Opening Symbol Rules

- An opening symbol belongs to the actual operable sash or leaf and anchors to its resolved geometry.
- Do not draw opening symbols on FIXED regions.
- Left/right variants mirror correctly when the opening/handing semantics explicitly specify the variant.
- A tilt-turn/two-axis symbol communicates both side-opening and upper tilt according to the approved visual convention.
- The triangle/apex-to-handle-side convention applies only as described by the supplied human reference; do not infer handing.
- Inside/outside view is a separate explicit concern where required.
- Sliding/opening direction is visually distinct from the standard side-hung triangular symbol. Detailed sliding hardware behavior remains UNKNOWN absent separate evidence.
- Functional role (`WINDOW_REGION` / `DOOR_REGION`), field type (FIXED / OPERABLE), opening mode, handing, and view direction are separate concepts.
- Do not invent opening geometry merely to improve appearance.

See [reference evidence rules](REFERENCE_EVIDENCE_RULES.md) for the scope and limits of the human reference set.
