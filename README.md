# FacadeFlow

New clean-sheet FacadeFlow application.

The previous `FacadeFlow-Demo` repository remains a training/reference project. This codebase starts the new real workflow from scratch.

## Concept 01

- preserve the established header visual language;
- keep the Nadezhda logo;
- expose only one main action: **Създай оферта**;
- open a minimal **Нова оферта → Клиент / Обект** workspace shell;
- do not migrate AI, PROFILE DATA, CAD or old navigation.

## Commands

```powershell
npm install
npm run verify
npm run dev
```
